Version 2.0 — Platform Modernization

Current

Released: Q2 2026  |  Change Request: CHG-2026-047

Changes

  • Platform API upgraded to v2. All internal SOC tooling now integrated with the current Platform API.
  • Dashboard modernization: redesigned Operations Centre with real-time analytics.
  • Session authentication improvements and role-based access control enhancements.
  • Infrastructure services migrated to current platform standard.
  • Performance improvements across Incident, Asset, and Report management modules.
  • Notifications subsystem redesigned for lower latency.
  • Audit logging expanded to cover all data-modifying operations.
  • Technology refresh: underlying infrastructure components upgraded per Q2 2026 roadmap.

Known Operational Notes

  • Compatibility services remain active during the validation window. Retirement scheduled post engineering sign-off.
  • Older system components remain online temporarily to support rollback procedures.
  • Platform Upgrade Programme is currently at 85% completion. Identity Platform component is pending final approval.
