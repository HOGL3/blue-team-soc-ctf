Help & Support

Apex Global Solutions – SOC Platform Documentation

Quick Start

  • Logging In Use your Apex Global employee credentials. Contact your SOC manager if you are locked out.
  • Dashboard The dashboard provides a real-time overview of active incidents, asset status, and unread notifications. Live data is retrieved from the Platform API v2.
  • Creating an Incident Navigate to Incidents → Create Incident. Assign a severity, category, and analyst before saving.
  • Generating Reports Navigate to Reports → Create Report. Link the report to an incident where applicable.

Platform Information

  • Current Platform Version Platform API v2.0 — Infrastructure Modernization (Validation Phase)
  • Migration Status Platform modernization is 85% complete. Compatibility services remain active during the validation window. See Release Notes for details.
  • API Documentation The Platform API v2 schema is available to authenticated users at /api/v2/docs/.
  • Supported Browsers Chrome 120+, Firefox 121+, Edge 120+. Internet Explorer is not supported.
